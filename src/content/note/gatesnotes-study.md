## 一、站点概况

| 维度 | Gates Notes | Wentao's blog |
| --- | --- | --- |
| 定位 | 比尔·盖茨的个人博客，聚焦全球健康、能源、教育 | 个人研究与沉淀阵地，企业研究 + 前沿 AI |
| 域名 | gatesnotes.com | fanwentao.cn |
| 技术栈 | 自研（ASP.NET + React 混合渲染） | Astro 5 静态站 |
| 内容量 | ~300 篇文章 + 书评 + 年度问答 | 7 篇（起步阶段） |
| 更新频率 | 每月 2-4 篇 | 目标每周 1-2 篇 |

## 二、信息架构对比

### Gates Notes 的顶层分类

Gates Notes 不用传统的「分类 + 标签」体系，而是按**身份角色**划分：

1. **Work** — 盖茨基金会工作（Save lives / Energy / Education）
2. **Books** — 书评（按经济学、教育、小说等主题分类）
3. **Meet Bill** — 个人介绍（Source Code / Philanthropy / Microsoft / Family / Games / Podcasts）

这个分类逻辑的核心是「人以群分」而非「内容以题分」——读者关注的是盖茨这个人，其次才是话题。

### Wentao's blog 的分类

当前按**内容领域**划分（企业研究 / 前沿 AI / 随笔笔记），更传统但更清晰。

**可借鉴**：当内容量到 50+ 篇时，考虑加一层「书评」分区——书评是个人博客的高质量内容来源，也是建立专业形象的有效手段。

## 三、文章页设计对比

### Gates Notes 的文章页结构

```
┌──────────────────────────────────┐
│  大标题（H1，居中或左对齐）          │
│  by Bill Gates · 日期              │
│  分类标签                            │
├──────────────────────────────────┤
│                                    │
│  正文（单列，无侧边栏）               │
│  段落间距大，行高 1.7-1.8            │
│  章节编号：1、2、3…（视觉锚点）       │
│  内联链接用品牌色 + 下划线            │
│  图片有 caption                      │
│                                    │
├──────────────────────────────────┤
│  上一篇 / 下一篇（全宽卡片）          │
│  社交分享按钮                        │
│  相关文章（3 篇，卡片网格）           │
└──────────────────────────────────┘
```

### 已借鉴的元素

| 元素 | Gates Notes | Wentao's blog | 状态 |
| --- | --- | --- | --- |
| 单列正文、无侧边栏 | ✅ | ✅（移动端） | 已有 |
| 目录侧边栏（桌面端） | ❌ 无 | ✅ 有 | Wentao 更优 |
| 章节编号 | ✅ 数字 1/2/3 | ❌ 无 | 可考虑 |
| 上一篇/下一篇 | ✅ 全宽卡片 | ✅ 双列卡片 | ✅ 刚加 |
| 相关文章 | ✅ 3 篇卡片 | ✅ 3 篇卡片 | 已有 |
| AI 摘要 | ❌ 无 | ✅ 有 | Wentao 更优 |
| 社交分享 | ✅ 显眼按钮 | ❌ 无 | 可考虑 |

### 可借鉴的改进点

**1. 章节编号（视觉锚点）**

Gates Notes 在每个 H2 前标数字（1、2、3…），给读者一个进度感。当前我们的 H2 有左边框装饰，但没有编号。

实现方式：CSS counter
```css
.prose{counter-reset:section;}
.prose h2::before{counter-increment:section;content:counter(section);}
```

**2. 阅读时间估算**

Gates Notes 不显示阅读时间，但这是个人博客的标配。可在文章页 `post-meta` 区加一行「约 X 分钟」。

**3. 社交分享按钮**

Gates Notes 有明显的分享按钮（Twitter / Facebook / LinkedIn / Email）。对中文博客，可考虑微信/微博/复制链接。

## 四、首页设计对比

### Gates Notes 的首页

```
┌──────────────────────────────────┐
│  导航（Work / Books / Meet Bill）  │
├──────────────────────────────────┤
│  Hero：大图 + 个人名言              │
│  「My work is driven by…」         │
├──────────────────────────────────┤
│  最新文章（大卡片 + 摘要）           │
│  书评专区                           │
│  话题分类入口                       │
└──────────────────────────────────┘
```

核心特点：
- **个人品牌优先**：首页第一屏是盖茨的照片 + 一句话价值观
- **大卡片**：每篇文章有充足空间展示标题 + 摘要 + 配图
- **书评独立入口**：与文章平级，不是子分类

### Wentao's blog 的首页

当前：Hero + 双主题分区（企业研究 / 前沿 AI / 随笔笔记）+ 卡片列表 + 分页 + 标签云。

**已比 Gates Notes 做得好的地方**：
- 三主题分区比 Gates Notes 的大杂烩更清晰
- 标签云提供了更细粒度的发现路径
- 搜索框常驻 header

**可借鉴**：
- 首屏加一句个人价值主张（当前 Hero 只有标题和描述，可加一句「底子要硬，表达要软」式的 slogan）
- 大卡片模式（当前卡片偏紧凑，可考虑在桌面端给每张卡片更多空间）

## 五、移动端适配对比

Gates Notes 的移动端：
- 汉堡菜单 + 全屏抽屉式导航
- 文章单列，字号 16-18px
- 图片自适应宽度
- 无侧边栏（桌面端也没有）

Wentao's blog 刚修复的移动端：
- 汉堡菜单 + 下拉式导航（已改进：点击链接自动关闭 + 点击外部关闭）
- 文章单列，TOC 水平排列在顶部
- 480px 以下隐藏搜索框
- 上一篇/下一篇在 480px 以下变单列

**差距**：Gates Notes 的汉堡菜单是全屏抽屉（从右侧滑入），比我们的下拉式更现代。可考虑后续升级。

## 六、SEO 与内容策略对比

### Gates Notes 的做法
- 每篇文章有 structured data（Schema.org BlogPosting）
- URL 结构：`/文章标题-slug`（无日期，简短）
- 社交媒体卡片（Open Graph + Twitter Card）
- 站内搜索（全文搜索）

### Wentao's blog 当前状态
- ✅ Schema.org BlogPosting（jsonLd 已实现）
- ✅ URL 结构：`/posts/slug/`（无日期，干净）
- ✅ Open Graph + Twitter Card（BaseLayout 已实现）
- ✅ 站内搜索（标题 + 摘要级）
- ⏳ Sitemap 已提交搜索引擎（待操作）

**已对齐**，无需额外改进。

## 七、值得借鉴的 5 个具体改进

按优先级排序：

| 序号 | 改进 | 难度 | 优先级 |
| --- | --- | --- | --- |
| 1 | 章节编号（CSS counter，H2 前加数字） | 低 | P2 |
| 2 | 阅读时间估算（字数 / 300 字每分钟） | 低 | P2 |
| 3 | 首屏加一句 slogan / 价值主张 | 低 | P2 |
| 4 | 社交分享按钮（复制链接 + 微信二维码） | 中 | P2 |
| 5 | 汉堡菜单升级为全屏抽屉 | 中 | P3 |

## 八、Gates Notes 不值得照搬的地方

1. **个人照片大图**：盖茨是全球知名人物，照片就是品牌。个人博客不需要这种级别的个人展示。
2. **无标签体系**：Gates Notes 靠分类和搜索，没有标签。但标签对发现性很有帮助，特别是文章数少时。
3. **无目录侧边栏**：Gates Notes 的文章通常较短（2000-3000 词），不需要 TOC。我们的文章偏长，TOC 是必要的。
4. **无 RSS**：Gates Notes 不提供 RSS（这是个缺点，不是优点）。

## 九、总结

Gates Notes 的核心设计哲学是**内容优先、个人品牌驱动、极简 chrome**。这三点对个人博客都有参考价值，但具体实现上需要根据自己的定位调整。

Wentao's blog 在几个方面已经比 Gates Notes 做得好：
- 标签体系（发现性更强）
- TOC 侧边栏（适合长文）
- AI 摘要（差异化体验）
- 上一篇/下一篇导航（刚加）

下一步最有价值的改进是**章节编号**和**阅读时间**——这两个都是低成本的体验提升。
